# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep the discussion about the work. Report unacceptable behaviour privately to the maintainers through the contact listed on the repository's GitHub profile. Maintainers will review every report and respond in confidence.
